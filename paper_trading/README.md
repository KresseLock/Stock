# Paper Trading 前瞻驗證手冊

> 目的：在投入真錢前，用 **mode_b 風控參數 + 最新模型** 做向前實測（forward test），
> 驗證回測績效不是來自模型 lookahead。這是唯一沒有前視偏差的試金石。
>
> 起始日：2026-06-18 ｜ 初始資金：2,000,000 元 ｜ 風控：`configs/best_trading_params_mode_b.json`（已上線）

---

## 為什麼要做這個（一句話）
潔淨 OOS 驗證顯示：**無 lookahead 下界只有 +5.18% / MDD -32.41%（Calmar 0.16）**，
而樣本內全週期是 +47.37%。真實實盤落在下界與上界(+24.34%)之間，**必須實測才知道偏哪邊**。

---

## 每日流程（已自動化，一鍵無腦）
收盤後（約 15:30 三大法人更新完）執行一鍵腳本：
```
.\run_daily.ps1
```
它會自動：① `Auto_RUN.py -s all`（下載→重訓→推理→備份 Drive）→ ② `record_paper_trades.py`
自動把當日預測的買/賣掛單寫進 `trades.csv`，並回補先前 pending 掛單的成交判定。

**`record_paper_trades.py` 自動做掉的事（無前視偏差）：**
1. 解析 `predictions/prediction_<date>.txt` 的買/賣掛單 → 自動新增列（掛單日 = 次一交易日）。
2. 隔日該交易日價格到位後，依**真實次日價格**自動判定 `是否成交 / 成交價`：
   - 買（限價）：次日 `最低價 ≤ 建議掛單價` 才成交；否則 `N`（限價買不到，這就是搓合率原始資料）。
   - 賣（開盤賣）：以次日 `開盤價` 成交。
3. FIFO 配對賣單 → 自動算買進持倉的 `出場價 / 持有天數 / 損益%`（已扣 0.585% 摩擦）。

> 冪等：重跑同一天不會重複寫入。次一交易日尚未產生的掛單會維持 pending，等下次跑自動回補。

**仍需手動 / 交給 trading_sim 的部分：**
- `daily_portfolio.csv`（總資產、累計報酬、距高點回撤、避險紅燈）需完整資金/T+2 模擬 → 每日收盤手動更新一列，**或**直接跑 `python trading_sim.py --start <上線日> --end <今日>` 取得完整資產曲線與 Excel 報表。
- `損益金額 / 股數` 同理（需資金配置），本工具只填無歧義的 `損益%`。

## 三個必看指標（對應回測假設）
| 指標 | 怎麼算 | 為什麼重要 |
| :--- | :--- | :--- |
| **搓合率** | trades.csv 中 `是否成交=Y` 筆數 ÷ 總掛單筆數 | mode_b 用折價買進(`markup_pct -1.5`)，掛不到單則回測報酬會大幅縮水 |
| **報酬落點** | daily_portfolio.csv `累計報酬%` | 是否落在下界 +5% ~ 上界 +24% 之間？掉到 +5% 以下 = 泛化力比預期差 |
| **回撤控制** | daily_portfolio.csv `距高點回撤%` | 停損 -6.5% 與避險紅燈是否如期保護？逼近 -32% = 觸及下界風險 |

## 並行監控（每週至少一次）
```
python scripts\analyze_regime_stability.py
```
報告存於 `reports/regime_stability_report.txt`。**判讀重點：別被單一 PSI 高嚇到，要看「PSI 高 _且_ RankIC 崩」才算失效。** 以下為 2026-06-18 首次基準判讀，日後對照變化即可。

### ✅ 健康（可繼續驗證，不需動作）
- **OOS 尾部 Alpha 為正**（第 3 段）：Top 1% 超額 Alpha 仍 > 0（基準 +1.73%）。這是選股力沒退化的**核心鐵證**。
- **OOS RankIC 顯著為正**（第 2 段）：All RankIC > 0 且 t-stat 顯著（基準 +0.0225 / t≈12）。滾動 RankIC（第 1 段）沒持續下滑。
  - *最後一天價差顯示 `+nan%` 屬正常*：當天「未來報酬」尚未發生，無法計算，非 bug。
- **動能股 IC ≥ 弱動能股 IC**（第 6 段）：兩組皆強正（基準 強 +0.154 / 弱 +0.097）→ 趨勢股上沒失效。

### 🔴 該按停 / 回模式 A 重設計因子（任一觸發）
- **OOS RankIC 掉到接近 0 或轉負**，或 t-stat 不再顯著。
- **OOS Top 1% Alpha 由正轉負**（選股力真正失效）。
- 上述發生**同時** PSI 嚴重漂移 → 確認是因子失效而非單純市場位階改變。

### 🟡 觀察（不需動作，但留意切換點）
- **因子翻號**（第 5 段）：`ret1/RS_1d` 等短期反轉因子 IS 為負、OOS 翻正（均值回歸→動能）。模型目前正確吃到，但**牛市轉震盪/空頭時可能反咬** → 那時 RankIC 會開始掉，即降載訊號。
- **空頭市況模型 edge 弱**（第 2 段）：OOS Bear RankIC 很低（基準 +0.008），但 regime 過濾器在 Bear 已實質空倉，設計上互補、非漏洞。
- **大盤層級特徵 PSI 嚴重漂移**（第 4 段）：`market_*_ma20` PSI ≥ 0.25 屬「市場從 2 萬漲到 4 萬」的 regime 訊號本身，搭配 RankIC 沒崩 → **不觸發失效判定**。

## 加碼決策門檻
- 報酬 ≥ **+5%（下界）** 且 MDD 未破 -32% → 可開始**小額實單**。
- 報酬接近 **+24%（上界）**、搓合率高、訊號健康 → 才考慮**放大資金**。
- 報酬轉負或 MDD 逼近 -32% → 先別投真錢，回頭查是否模型 lookahead 在作祟。

## 建議驗證期長度
至少 1~2 個月，且最好涵蓋一次 regime 切換（震盪↔牛↔熊），才測得出風控在不同市況的真實表現。

## 欄位說明（trades.csv）
- `訊號類型/訊號值%`：買進看 D1（建議掛單依 D1 信心加價），賣出看 D3。
- `出場原因`：D3轉弱 / 停損 / 移動止盈 / 最少持有到期 / 避險紅燈出清。
- `持有天數`：注意 mode_b `min_hold_days=10`，未滿 10 天不應主動換股。
